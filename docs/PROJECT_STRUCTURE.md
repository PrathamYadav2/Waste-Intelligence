# Project Structure
See README.md and `tree` output. `app/` UI, `src/` engines + API, `configs/` settings, `sql/` schema, `scripts/` stage scripts, `models/` & `data/` (git-ignored contents), `reports/` outputs, `tests/`, `docs/` (copies of these documents live at repo root of docs). 

**Migration note:** if an existing project layout conflicts, do not delete or overwrite: map old folders to these ones in a MIGRATION_PLAN.md and move files only after confirmation.
